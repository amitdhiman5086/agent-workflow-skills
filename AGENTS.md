# Agent instructions

This folder holds the team's issue-to-PR workflow skills (`skills/`), routine prompts
(`routines/`) and docs (`README.md`).

- When the user asks to set up, install or onboard: follow `skills/workflow-setup/SKILL.md`.
- When editing skills: keep the standard `SKILL.md` format (front matter with `name` and
  `description`), plain language, and the rule that nothing posted to GitHub mentions cost,
  tokens or spend.
- Keep `README.md` (flow, steps, labels, install) in sync with any skill change.
